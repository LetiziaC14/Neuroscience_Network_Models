## Project Goal
This project develops a unified mean-field theory and simulation framework to understand how random two-layer neural networks transform clustered noisy sensory patterns into higher-dimensional cortical representations, and how this affects dimensionality, cluster expansion, and linear readout performance.
Two complementary sources are integrated:
1) The main paper analyzes feedforward random projections, cluster statistics, and readout classification.

2) The notes file introduces the general model family (feedforward, feedforward-with-inhibition, recurrent), provides full mean-field derivations, and analyzes dimensionality across architectures (Sections I–IV) 

Together, they provide a complete analytic and computational picture of how random networks reshape data.
